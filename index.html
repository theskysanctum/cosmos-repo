CosmOS packages

The pieces of CosmOS as ordinary Fedora packages. Adding this repository is optional; nothing on your system uses it unless you do.

Add the repository

sudo rpm --import https://theskysanctum.github.io/cosmos-repo/RPM-GPG-KEY-cosmos
sudo curl -o /etc/pki/rpm-gpg/RPM-GPG-KEY-cosmos https://theskysanctum.github.io/cosmos-repo/RPM-GPG-KEY-cosmos
sudo dnf config-manager addrepo --from-repofile=https://theskysanctum.github.io/cosmos-repo/cosmos.repo

Packages and repository metadata are signed (GPL-3.0-or-later). Key fingerprint: A317 4049 212E 0D8E FD18 DE16 48EE 8F0D B26F 39F2

or install the package that contains the same file: sudo rpm --import https://theskysanctum.github.io/cosmos-repo/RPM-GPG-KEY-cosmos && sudo dnf install https://theskysanctum.github.io/cosmos-repo/noarch/cosmos-repo-0.4.0-1.20260926175237.fc44.noarch.rpm

Install what you want

sudo dnf install cosmos-shop          # the Shop (curated apps, Expansion Packs, game downloads)
sudo dnf install cosmos-files         # a file manager that shows only your files and drives
sudo dnf install cosmos-controllers   # controller lights, rumble, gyro
sudo dnf install cosmos-desktop       # the whole desktop

Packages that change how the machine works (the login screen, the admin service, the sudo shims, recovery) are separate and only installed when you ask for them: cosmos-login, cosmos-kronos, cosmos-sudo-shims, cosmos-recovery.

Packages in this repository

  • cosmos-android: Android (Waydroid) for games, with a button-to-touch mapper
  • cosmos-common: CosmOS shared modules: the app policy, the curated catalog, Expansion Packs and the task window
  • cosmos-controllers: Controller Customizer: lights, rumble, motion and adaptive triggers
  • cosmos-desktop: The CosmOS desktop for a normal Fedora
  • cosmos-files: CosmOS Files: a file manager that shows only your files, drives and removable media
  • cosmos-files-udisks: Lets the account named "user" mount internal drives from CosmOS Files without a password (opt-in)
  • cosmos-firewall: The CosmOS firewall zone and its named doors (firewalld)
  • cosmos-gamebox-bundled-emulators: RetroArch, Dolphin, PCSX2 and MKXP-Z as GameBox bundles them
  • cosmos-gamebox: GameBox: the game and emulator frontend (code and session)
  • cosmos-gamebox-emulators: xemu, Flycast and extract-xiso, built from source
  • cosmos-gamebox-full: GameBox with everything: emulators, Wine, streaming and music
  • cosmos-gamebox-music-1: GameBox menu music, part 1 of 2
  • cosmos-gamebox-music-2: GameBox menu music, part 2 of 2
  • cosmos-gamebox-music: GameBox menu music (all tracks)
  • cosmos-gamebox-streaming: GameBox streaming: Sunshine and Moonlight binaries
  • cosmos-gamebox-tools: Compiled helpers for GameBox: Skyscraper (game art scraper) and the Millennium installer
  • cosmos-gamebox-wine: The Wine build GameBox runs Windows games with
  • cosmos-gamebox-wm: GameBox's own small X window manager (consolewm)
  • cosmos-image: Everything the CosmOS image contains
  • cosmos-input: CosmOS controller input: any gamepad becomes a keyboard and mouse, plus an on-screen keyboard
  • cosmos-kronos: Kronos: the CosmOS admin service, with a tamper-evident audit log
  • cosmos-login: The CosmOS login screen (a greetd greeter) with profiles, PINs and a Desktop or GameBox choice
  • cosmos-plymouth: The CosmOS boot splash (plymouth theme)
  • cosmos-portal: CosmOS file dialog for other apps (an xdg-desktop-portal FileChooser backend)
  • cosmos-recovery: CosmOS recovery: a no-shell app that can roll back the OS, reset the admin passphrase or a PIN
  • cosmos-remote: Remote Access: SSH keys and the Webtop development desktop
  • cosmos-repo: The CosmOS package repository (optional)
  • cosmos-shell: The CosmOS desktop shell: bar, launcher, lock screen, profiles and the session
  • cosmos-shop: The CosmOS Shop: curated Flatpaks, packages, AppImages, Expansion Packs, and game downloads
  • cosmos-sudo-shims: Never type sudo: commands that need root ask the admin service for it
  • cosmos-theme: CosmOS fonts and backgrounds
  • cosmos-theme-defaults: The CosmOS dark look as the system default for GTK, Qt and notifications (opt-in)
  • cosmos-updates: Updates for Flatpaks, AppImages and the system in one place
  • cosmos-vm-manager: Virtual Machines: a QEMU front end with host device passthrough
  • cosmos-winpack: Game Packs: a Windows game as one SquashFS file that runs under any Proton
  • cosmos-wm: cosmos-wm: the CosmOS Wayland compositor
